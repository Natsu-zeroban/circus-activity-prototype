# 马戏团原型

小型版本活动玩法形式验证网页。

## 在线体验

发布后通过 GitHub Pages 访问。进入页面后，点击当前主线节点推进；可拖动地图回看已探索区域，也可点击支线与信息流节点。

## 本轮验证内容

- 10个主线剧情节点与3个战斗占位节点
- 4个可选支线节点
- 10个信息流节点，其中3个为带事件插画的孤儿派遣调查
- 旧节点保留、唯一下一节点显现、镜头跟随与地图拖动
- 5名孤儿按主线进度加入，均有独立形象、经历、能力与行动局限
- 3道单次调查题，通过现场画面、环境记录与人物档案进行推断，不直接展示答案条件
- 难度从单人环境判断，递进到双人互补与三人协作
- 支线与信息流完成后在节点旁显示完成标记

详细规则见 [形式验证说明.md](形式验证说明.md)。
