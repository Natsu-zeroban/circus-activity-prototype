# 马戏团原型

小型版本活动玩法形式验证网页。

## 在线体验

在线地址：https://natsu-zeroban.github.io/circus-activity-prototype/ 。点击节点“查看”内容，再选择“前往”；节点完成后退场。每一日使用独立的循环剧场背景。

## 本轮验证内容

- 10个主线剧情节点与3个战斗占位节点
- 4个可选支线节点
- 10个信息流节点，其中3个为带事件插画的必经线人派遣调查
- 三日独立的斜俯视街区地图，路线贴合街道转折；当前主线保留到前往下一主线时退场，支线与信息流不移动局长
- 9名线人分属三日临时网络，跨日离队，档案按指定节点永久解锁
- 3道单次派遣事件，题面只保留场景目标、派遣人数和必要提示；候选线人以能力 tag 与风险 tag 支持判断，详细资料集中在人物档案
- 提交后右侧人选列表完全替换为不剧透成败的简要后续，再进入按角色单独编写的交替立绘对话，最后显示中央成功/失败标题；派遣成败不改变后续主线，不再设置好感度
- 每日最终主线在当日全部支线与信息流完成前保持隐藏

详细规则见 [形式验证说明.md](形式验证说明.md)。
