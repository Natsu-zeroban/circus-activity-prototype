# 马戏团原型

小型版本活动玩法形式验证网页。

## 在线体验

发布后通过 GitHub Pages 访问。点击节点“查看”内容，再选择“前往”；节点完成后退场。每一日使用独立的循环剧场背景。

## 本轮验证内容

- 10个主线剧情节点与3个战斗占位节点
- 4个可选支线节点
- 10个信息流节点，其中3个为带事件插画的必经线人派遣调查
- 三日独立的斜俯视街区地图，路线贴合街道转折；当前主线保留到前往下一主线时退场，支线与信息流不移动局长
- 9名线人分属三日临时网络，跨日离队，档案按指定节点永久解锁
- 3道单次调查题，通过现场画面、环境记录与人物档案进行推断，不直接展示答案条件
- 派遣成败写入后续主线文本，不再设置好感度
- 每日最终主线在当日全部支线与信息流完成前保持隐藏

详细规则见 [形式验证说明.md](形式验证说明.md)。
